Step 2: Add the browser extension

StillSpace also needs its free extension to block websites in Chrome, Edge and Brave. Without it, website blocking will not work properly.

⬇ Download the extension

1. Unzip the file.
2. Open chrome://extensions (or edge://extensions) and turn on Developer mode.
3. Click Load unpacked and choose the unzipped StillSpace-Extension folder.
4. Open StillSpace, go to Blocklist, and check it says the extension is connected.

Windows

1. Run the installer. If Windows SmartScreen appears, choose More info, then Run anyway (the app is new and not yet widely recognised).
2. Open StillSpace. Right-click it and choose Run as administrator the first time, so website blocking can edit the hosts file.

Browser extension

For page-level blocking (like youtube.com/shorts) and the blocked page, add the StillSpace Blocker extension to Chrome, Edge or Brave. The Support page has the steps.
