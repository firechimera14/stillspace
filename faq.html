FAQ

What is StillSpace?

A desktop study app with focus sessions, website and app blocking, a planner, streaks and collectible creatures.

Do I need the browser extension?

Yes, for website blocking. Download it from the Download page and load it in Chrome, Edge or Brave. The app also reminds you and has an Open extension folder button on the Blocklist page.

Is it free?

Yes. StillSpace is free to download and use.

What happens when my timer ends?

Everything is unblocked automatically. There is no unlock code to remember.

Can I stop a session early?

Yes, through the emergency override, which asks you to type a passage by hand so quitting is a conscious choice.

How does blocking work?

StillSpace edits your hosts file for websites, closes blocked apps, and uses a browser extension for specific pages. Someone with admin rights can always bypass it, so it works best as a commitment tool.

Does it work on iPhone or Android?

Not yet. Windows and macOS only for now.

What data do you collect?

None. Your tasks and settings stay on your computer. See the Privacy page.
